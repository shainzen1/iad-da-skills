# ki-log

Rohe Prompt-Protokolle. Grundlage für das Hilfsmittelverzeichnis, das die Schule zur
Diplomarbeit verlangt, und Beleg hinter der Eigenständigkeitserklärung.

- Eine Datei pro Session: `DD-MM-YY-thema-slug.md`, Vorlage `_template.md`
- Nur die eigenen Prompts, wörtlich, nummeriert. Keine Antworten, keine Zusammenfassungen.
- Tippfehler und Mundart bleiben drin. Nichts nachträglich schönen.
- Neues Tool oder neuer Zweck: eine Zeile in `da-hilfsmittel.md`.

Liegt hier bei den Arbeitsdateien statt in einer Notizen-App, weil es Beleg ist und nicht
Wissen. Es geht am Ende als Verzeichnis in die Dokumentation.
